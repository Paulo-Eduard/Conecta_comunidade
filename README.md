# 🌍 Conecta Comunidade

O Conecta Comunidade é uma plataforma educacional criada com o objetivo de promover inclusão digital e facilitar o acesso ao conhecimento através da tecnologia.

O projeto foi desenvolvido para conectar alunos e professores em um ambiente simples, intuitivo e colaborativo, oferecendo cursos, quizzes, conteúdos educativos e uma comunidade para troca de experiências e aprendizado.

Além de servir como ferramenta de ensino, o Conecta Comunidade também representa nossa evolução como desenvolvedores, reunindo conceitos de desenvolvimento Full Stack, banco de dados, autenticação, APIs e experiência do usuário.

---

## 🚀 Funcionalidades

### Para Alunos

* Participar de cursos
* Realizar quizzes
* Acompanhar o próprio desempenho
* Interagir na comunidade
* Acessar conteúdos educacionais

### Para Professores

* Criar e gerenciar cursos
* Criar e editar quizzes
* Publicar conteúdos educativos
* Acompanhar alunos
* Moderar a comunidade
* Criar avisos e comunicados

## 📦 Como Executar

### Backend

```bash
cd backend

pip install -r requirements.txt

uvicorn app.main:app --reload
```

A API estará disponível em:

```text
http://127.0.0.1:8000
```

Documentação:

```text
http://127.0.0.1:8000/docs
```

### Frontend

```bash
cd frontend

npm install

npm run dev
```

A aplicação estará disponível em:

```text
http://localhost:5173
```

O Conecta Comunidade foi desenvolvido para incentivar o aprendizado digital e criar um ambiente acessível onde alunos possam evoluir através de cursos, atividades e interação com professores.
